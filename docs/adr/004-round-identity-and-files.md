# Point identity and round files

Keep the source file and heading with each point. M numbers identify their
original points even if the approved wording changes. For positional numbers,
match unique exact text within the same source. Reopen unmatched text with an
empty mark and proof. Keep a positional change link only when unique exact text
identifies the same point. Clear ambiguous links and keep their decisions.

Open a new round only from a structurally complete check. The validation of its
marks does not depend on the current approved text, which may have changed.
Write the new file and archive in the output directory. Publish the archive
first, then replace the current check. A retry can reuse an identical archive
from an interrupted write. An archive with different bytes is kept and reported.
If a stopped process leaves the write lock behind, the numbered refusal explains
how to clear it after confirming no check is running.
